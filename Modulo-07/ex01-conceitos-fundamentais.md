# Exercício 1 - Conceitos fundamentais

## a. Qual é a função do AppServer?

Na minha visão, o AppServer é o programa que faz o Protheus funcionar. Ele recebe o que o usuário faz no SmartClient, processa as informações e se comunica com o banco de dados quando precisa buscar ou salvar dados.

## b. O que é o RPO?

O RPO é onde ficam guardados os programas compilados do Protheus. Sempre que alguma rotina é executada, o AppServer utiliza os arquivos que estão armazenados nele.

## c. Para que serve o Configurador (SIGACFG)?

O Configurador é a ferramenta usada para configurar o Protheus. É nele que podemos criar tabelas, adicionar campos, configurar usuários, permissões e fazer outras alterações no sistema.

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

O campo Real é armazenado no banco de dados e permanece salvo na tabela. Já o campo Virtual não fica gravado, pois seu valor é gerado pelo sistema somente quando for necessário.
