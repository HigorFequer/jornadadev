# Localização dos fontes

O enunciado principal exige os fontes diretamente na raiz de `TCC/`, com os
nomes exatos abaixo. Eles foram mantidos nessa posição para que a validação
automática os encontre sem duplicação:

- `../STTZZ1.PRW`
- `../STTZZ2.PRW`
- `../STTZZLIB.PRW`
- `../STTISO.PRW`

Esta pasta existe somente como referência à estrutura citada no checklist da
rubrica. Não contém cópias dos fontes para preservar o critério de zero
duplicação de código.
